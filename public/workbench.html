Execution setup

运行设置

目标应用地址

在仓库根目录 .env 中通过 APP_BASE_URL 指定目标；默认只连接本地演示站。

主机安全白名单

测试外部环境前，将精确主机名加入 APP_ALLOWED_HOSTS；未授权主机会在浏览器启动前被拒绝。

并发 worker

使用 PLAYWRIGHT_WORKERS 配置正整数并发数；CI 未配置时默认使用 2 个 worker。

视觉模型

视觉测试使用独立入口 npm run test:ai，需配置模型密钥和模型名称，不影响确定性 smoke。

这些设置由进程环境变量读取。修改 .env 后重启工作台/测试进程；密钥不会写入浏览器或本地用例文件。
