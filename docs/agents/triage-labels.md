# Triage Labels

This file maps the canonical triage roles used by the engineering workflow to GitHub labels.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | Work is waiting for more information. |
| `ready-for-agent` | `ready-for-agent` | The issue is specified and ready for agent implementation. |
| `ready-for-human` | `ready-for-human` | The issue requires human implementation. |
| `wontfix` | `wontfix` | The issue will not be actioned. |
