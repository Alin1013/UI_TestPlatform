# Issue tracker: GitHub

Issues and PRDs for this repository live in GitHub Issues. Use the `gh` CLI from this checkout; it infers the repository from the configured GitHub remote.

## Conventions

- Create issues with `gh issue create --title "..." --body "..."`.
- Read an issue and its comments with `gh issue view <number> --comments`.
- List open issues with `gh issue list --state open` and add label/state filters when useful.
- Comment, edit labels, and close issues with the corresponding `gh issue` commands.
- Pull requests are not a triage request surface; only issues are triaged as incoming work.
